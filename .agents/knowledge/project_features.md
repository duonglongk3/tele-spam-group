# Core Features of TeleShopBot

This document summarizes the most useful features of the **TeleShopBot Platform** from the perspective of an MMO practitioner/online seller (non-technical). The Agent uses this document as reference material when explaining features on Telegram.

---

## 1. Merchant Features (Admin Web Dashboard)
The system provides an intuitive web administration panel that allows shop owners to easily set up and monitor their business without coding:
* **Product & Category Management**: Add, edit, and categorize digital products (accounts, license keys, downloadable files). You can upload a list of accounts/keys at once for the bot to deliver to customers.
* **Sleek Web Admin Dashboard**: View sales reports, track order counts, check balances, and view customer information visually.
* **Manage Multiple Shop Bots (Multi-bot)**: Add and manage multiple Telegram bots under a single admin panel. Each bot can be configured to sell a different product line.
* **Direct Chat System**: Chat directly with customers from the Web Dashboard when they message the Telegram bot. Supports text, images, videos, voice messages, and stickers.
* **Flexible Customization**: Customize the welcome message, display currency, and bot language with a few clicks.

---

## 2. Customer Features (Telegram Bot Interface)
The Telegram bot interface is optimized for speed and convenience, letting customers shop with ease:
* **Interactive Command Menu**: Customers browse categories, view product details, and buy using quick button clicks (no complex commands needed).
* **24/7 Automated Purchase**: The system automatically verifies the customer's balance, deducts the payment, and delivers the digital product in chat instantly (even while you are asleep).
* **Quick Product Search**: Customers type keywords (e.g., "Netflix") to let the bot search and return matches instantly.
* **Multi-Language Support**: The bot automatically displays in the customer's language or lets them choose from 14 supported languages.

---

## 3. Automated Payments & Affiliate Systems
* **Auto Deposit via QR Code**: Customers click deposit, enter the amount, and scan the QR code. The system detects the bank transfer and credits their balance in seconds.
* **Direct Checkout (Low Balance)**: If a customer has insufficient balance, the bot creates the order and displays bank details + QR code for the exact amount. The customer scans, pays, and receives the goods immediately.
* **Affiliate (Referral) System**: Generates unique links for affiliates. When new users buy through an affiliate's link, commission is credited automatically according to the percentage configured in the admin dashboard.
